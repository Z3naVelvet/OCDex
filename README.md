# OCDEX 2.0

Desktop Original Character Encyclopedia with a red/white/gray handheld-Pokédex-inspired UI.

Features:
- AppData persistence at `%APPDATA%\\OCDEX`
- Separate universes
- Link an OC to multiple universes
- Type selection and custom types
- Embedded/resized artwork
- Optional background removal
- Softer pixelization + CRT scanlines/glow
- Animated startup screen
- Shared OCDEX logo for startup, window and taskbar icon
- Smooth artwork sliding
- Human-relative size comparison
- Global `ocdex_music` soundtrack at 90%

Run:
    py -m pip install -r requirements.txt
    py main.py

Put `ocdex_music.ogg` (or .mp3/.wav/.flac/.mid/.midi) beside main.py if desired.
